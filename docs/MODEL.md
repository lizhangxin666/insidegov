# 模型说明

## 研究问题

在财政、资源和组织约束下，异质地方政府与企业如何通过重复互动、地区竞争和产业网络共同塑造企业选址与产业演化？何时形成产业集聚，何时演化为政策竞赛、财政风险与产能过剩？

## 通用底座与场景模块

通用底座包括主体身份、目标与资源，客观状态与主观信念，权限和组织关系，合同承诺，时间、市场和事件日志。

三个场景共享底座：招商阶段启用政策包竞价；签约后启用项目进度、合同节点和信誉更新；投产后启用供应链进入、集聚效应、需求周期和产能利用率。

## 主要机制

1. 政府政策是土地、补贴、股权、信贷、审批和人才服务的组合；
2. 政府行动同时受意愿、资源能力、任期和内部协调约束；
3. 企业根据异质偏好评价城市，政策价值按主观兑现概率折算；
4. 承诺以结构化合同进入财政跨期账本；
5. 履约结果改变每家企业的主观信用，而非只改变统一评分；
6. 龙头企业落地提高供应商进入收益，形成集聚正反馈；
7. 总产能超过需求后，利用率和价格下降并产生救助压力。

## 证据层级

- 《置身事内》支持地方政府深度参与、条块协调、财政土地约束、官员激励、产业投资与集聚等现实机制；
- 动态信誉、主体主观感知和信息传播是本项目的模型扩展；
- 默认参数是合成演示参数，不代表任何真实城市或企业；
- 模拟输出是假设条件下的机制结果，不是因果识别或现实预测。

## 校准路线

后续可依次加入：公开财政和土地数据校准、企业选址案例校准、专家访谈、历史事件回放、参数敏感性分析、与真实调查分布对照。
