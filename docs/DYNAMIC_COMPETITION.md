# 动态竞争、企业退出与政府救助

该模块补齐核心世界此前缺失的后半段闭环：

```text
产业项目成功
→ 竞争城市观察并模仿招商
→ 同类产能集中进入
→ 需求冲击与利用率下降
→ 企业连续亏损并申请救助
→ 招商局、财政局、市领导分别行动
→ 市场退出 / 无条件救助 / 附条件救助
→ 就业、财政、产能出清和僵尸企业分化
```

## 组织 Agent 与规则引擎的边界

- 招商局选择继续观察、定向模仿或激进模仿；规则引擎只核准财政和土地可承受的规模。
- 困难企业选择申请救助、自主重组或有序退出；企业不能直接改变政府预算。
- 招商局从就业和产业链角度提出意见；财政局依据私有储备底线给出硬上限；市领导选择拒绝、无条件救助或附条件救助。
- 规则引擎最终扣减财政、压减产能和岗位、取消未履行承诺、释放土地并更新企业生命周期。

所有决策都保存为 `imitation_decisions`、`rescue_decisions` 和 `action_audits`。其中明确区分 Agent 建议、财政硬上限和最终执行结果。

## 企业生命周期

| 状态 | 含义 |
|---|---|
| `active` | 正常经营 |
| `distressed` | 连续亏损或产能利用率过低 |
| `restructured` | 接受附条件救助并压减产能、岗位 |
| `zombie` | 多次无条件救助后仍长期低利用率 |
| `exited` | 救助被拒或市场化退出，停止生产并释放部分土地 |

## 三制度反事实实验

接口：

```bash
curl 'http://localhost:8000/experiments/dynamic-competition?seed=42&quarters=24&demand_shock=-0.42'
```

实验固定：

- 同一 seed 和初始城市、企业；
- 同样的激进城市模仿机制；
- 同样在 Q10 发生 42% 需求冲击；
- 只改变救助制度。

前端入口为首页右侧“退出救助实验”。用户可以比较三种制度的就业、退出企业、僵尸企业、救助支出、产能和利用率，并查看一次完整救助会商。

## 结论边界

该实验验证的是模型内部的机制差异，不是现实政策效应估计。救助额度、产能压减比例、亏损阈值和退出期限仍需要真实案例、企业财务数据与专家编码校准。多 seed、机制消融和参数敏感性分析是用于研究结论的必要步骤。
