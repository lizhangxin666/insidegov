# 无答案标签企业的证据型尽调研究

## 研究问题

面对一家没有现成成功/失败标签的新企业，政府无法直接知道它是不是低质项目。
InsideGov 现在研究的是：

> 企业质量未知、披露具有策略性且调查有成本时，何种证据获取与承诺程序能够减少
> 误签、误拒和调查成本？

这不是让模型“识别坏企业”，而是比较程序的判别力。项目质量由资金闭合、技术成熟、
市场验证、治理信用和交付能力五个连续潜在因子构成；这些因子只生成证据和事后结果，
不会进入政府 Agent 的观察。

## 自主性与刚性边界

Agent 自主决定：

- 谁在本轮发起调查；
- 从当前授权候选中查资金、技术、市场、治理还是交付；
- 证据是否足够，继续调查还是停止；
- 正式推进、可逆试点、补证再议或否决；
- 使用 LLM 时，每一步的选择和理由由模型生成并保存。

规则引擎只负责：

- 角色权限和调查成本；
- 企业材料、外部核验与材料冲突的确定性生成；
- 贝叶斯式风险/不确定性更新；
- 已核实法律红线的强制拦截；
- 事后失败、财政损失和机会损失结算。

因此 Agent 有策略自主性，但不能凭空创造证据、资金或权限。审计记录显式保存
`hidden_quality_label_available=false` 和 `decision_used_hidden_label=false`。

## 五种程序

| 程序 | 主要证据 | 预期取舍 |
|---|---|---|
| 轻量筛查 | 企业提交材料 | 快且便宜，但容易被有说服力的材料影响 |
| 只做企业澄清 | 多轮追问企业 | 提高表达清晰度，仍缺外部交叉验证 |
| 独立证据核验 | 资金、技术、客户、信用、交付第三方证据 | 判别力提高，时间和成本增加 |
| 跨部门反方审查 | 独立核验＋主动寻找失败解释 | 校准略好，成本最高 |
| 自适应尽调＋分阶段承诺 | Agent 按信息价值选下一项证据，可转为试点 | 保留项目机会并控制不可逆财政敞口 |

## 当前确定性基线结果

默认矩阵为 5 种程序 × 8 个随机种子 × 8 家异质企业。结果是程序内部验证，尚不是
现实预测：

| 程序 | 失败项目召回 | 好项目特异度 | Brier | 平均天数 | 尽调成本 | 避免财政损失 | 误失机会 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 轻量筛查 | 0.0% | 100.0% | 0.189 | 7.0 | 3.36 | 0.00 | 0.00 |
| 只做企业澄清 | 0.0% | 100.0% | 0.188 | 13.0 | 6.08 | 0.00 | 0.00 |
| 独立证据核验 | 60.4% | 91.8% | 0.170 | 34.0 | 25.84 | 18.77 | 1.52 |
| 跨部门反方审查 | 60.4% | 91.8% | 0.168 | 41.0 | 33.44 | 18.77 | 1.69 |
| 自适应尽调＋分阶段承诺 | 60.4% | 91.8% | 0.168 | 32.8 | 27.40 | 15.80 | **0.15** |

关键含义不是“0.5 是正确阈值”，而是：只问企业不等于独立核验；严格否决虽然减少
财政损失，也可能误伤好项目；可逆试点把二元批准改造成序贯学习。阈值曲线同时报告
真正率和假正率，避免只展示“抓到了多少坏项目”。

## 如何运行与查看

```bash
uv run uvicorn insidegov.api:app --reload --port 8000
```

- `GET /experiments/due-diligence`：默认完整矩阵；
- `POST /experiments/due-diligence-matrix`：自定义 seeds、程序、阈值和认知模式；
- 前端首页点击“低质项目识别”，可从程序均值下钻到单个 seed、企业和证据链。

## 现实依据与外推边界

各地招商项目管理实践普遍强调全生命周期、部门协同、尽职调查和风险控制；企业投资
项目监管制度也强调事中事后核查。但当前参数仍是模拟校准参数。正式应用需要将历史
成功/失败项目分成校准集和留出集，盲评编码早期材料，并报告 ROC、Brier、假阳性、
假阴性和阈值敏感性。
