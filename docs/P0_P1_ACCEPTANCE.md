## P0：可玩、可恢复的真实 Demo

- 控制台不再使用预设结局，全部数据来自 API。
- 支持单季/连续推演、财政/需求/信用干预、分支与世界切换。
- 世界在 `.insidegov/worlds` 原子持久化，前端只保存最后一个世界 ID。
- API 服务重启后可从 JSON 恢复完整对象图。
- 支持完整世界 JSON 导出，包含私有参数、记忆、干预、事件和决策链。

## P1：真正多 Agent 与研究基础

- 招商局、财政局、市领导、龙头企业董事会具有异质目标、性格和私有信息。
- 每个 Agent 仅获取局部观察；财政储备底线不进入市领导观察，企业真实意愿不进入政府观察。
- 行动是结构化 Schema，不是自由文本直接改变世界。
- 政府内部存在“招商局提案—财政局工具级否决—市领导重组协调”三步过程。
- 财政局分别设定总财政成本、现金、股权、信贷敲口和首期支付上限；规则引擎二次校验。
- 最终方案必须输出每期金额、相对季度和履约触发条件，并转化为真实 `Promise` 对象。
- Agent 存储可检索记忆和最近复盘。
- DeepSeek 认知层与确定性基线共用同一行动协议，支持实验比较。
- 四类 Agent 分别具有招商竞争响应、财政风险收缩、否决边界遵守、企业效用一致性校准任务。
- 实验矩阵默认比较确定性策略、`deepseek-v4-flash`、`deepseek-v4-pro`，每组 5 个种子。
- 完整机制与无私有信息、无内部治理、无信用扩散、无供应链溢出共 5 组消融。
- 报告保存每次运行、指标均值、总体方差、选址分布和失败案例；LLM 回退不计入成功样本。
