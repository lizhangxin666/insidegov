# P0 / P1 验收记录

## P0：可玩、可恢复的真实 Demo

- 控制台不再使用预设结局，全部数据来自 API。
- 支持单季/连续推演、财政/需求/信用干预、分支与世界切换。
- 世界在 `.insidegov/worlds` 原子持久化，前端只保存最后一个世界 ID。
- API 服务重启后可从 JSON 恢复完整对象图。
- 支持完整世界 JSON 导出，包含私有参数、记忆、干预、事件和决策链。

## P1：真正多 Agent 与研究基础

- 市领导、财政局、龙头企业董事会具有异质目标、性格和私有信息。
- 每个 Agent 仅获取局部观察；财政储备底线不进入市领导观察，企业真实意愿不进入政府观察。
- 行动是结构化 Schema，不是自由文本直接改变世界。
- 政府内部存在“提案—财政否决/限额—市领导协调”三步过程。
- Agent 存储可检索记忆和最近复盘。
- DeepSeek 认知层与确定性基线共用同一行动协议，支持实验比较。
- 已建立财政风险敏感性和企业效用一致性校准，以及三类机制消融。

## 验证基线

- Python：Ruff 通过，12 项 pytest 通过。
- Web：TypeScript 和 ESLint 通过，Node 22 生产构建通过。
- 浏览器：世界加载、Q0 → Q1、3 条政府协调记录、分支创建全部通过，无控制台错误。
