# InsideGov 路线图

> 当前发布：v0.5.0。路线图按“能运行—能解释—能验证—能复用”推进。

## v0.1 世界骨架（已完成）

- 三座异质城市、企业、政策承诺和产业生命周期；
- 招商、履约、产业演化三个阶段共用连续状态；
- 确定性规则、CLI/API、随机种子和约束测试。

## v0.2 组织与认知（已完成）

- 招商局、财政局、市领导、企业董事会的异质目标与私有信息；
- “提案—财政审核—领导协调”内部治理；
- 结构化行动、记忆、复盘、DeepSeek 适配与安全降级；
- Web 控制台、原子持久化、分支、干预和完整导出。

## v0.3 政策实验闭环（已完成）

- 政企双边协商、历史节点分支和自然语言干预确认；
- 指定季度 Agent 访谈；
- 文本材料抽取、参数溯源、人工确认；
- 世界 HTML/JSON 报告和共同随机数反事实比较。

## v0.4 校准与实验矩阵（已完成）

- 确定性/LLM 多策略、多种子和机制消融矩阵；
- 检查点续跑、失败分类、重试与降级统计；
- Agent 独立行为校准；
- 合肥—蔚来公开案例参数卡与模拟边界。

## v0.5 评委可验证演示闭环（当前版本，已完成）

- 五分钟六步“典型政企博弈回放”，数据由现场确定性模拟生成；
- 展示 Agent 私有信息、原始动作、财政硬上限、规则修正和跨期履约；
- 本级财政与三类联合产业基金分账审核、分期出资；
- Q3共同祖先、Q4财政冲击、Q16结果差异和因果事件链；
- 首页实验报告中心，支持策略/消融/seed/失败案例下钻和 JSON 导出；
- 15%—35%财政可动用比例 × 联合基金开关敏感性；
- 后端、前端、浏览器与离线确定性演示验收。

## v0.6 通用研究设计器（下一阶段）

- 图形化定义参数网格、分布、种子、指标、停止条件和并发上限；
- 本地任务队列的暂停、恢复和跨进程认知缓存；
- 通用敏感性曲线、置信区间和参数不确定性传播；
- PDF/Word 预处理、原文表格定位和证据审阅；
- 场景、规则和 Agent 插件规范；
- 可引用的 World Card、Model Card 与公开复现实验包。

## 暂不纳入近期范围

- 百万级 Agent、通用社交媒体模拟或完整 GIS；
- 把模拟输出表述为现实政策效果或未来预测；
- 未经人工确认就把模型抽取值作为事实参数。

产品范围和验收状态以 [PRODUCT.md](PRODUCT.md) 为准，研究假设与结论边界以
[MODEL.md](MODEL.md) 为准。
