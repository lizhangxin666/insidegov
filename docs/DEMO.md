# v0.5.0 五分钟演示与验收

## 演示目标

让评委在五分钟内验证三件事：博弈由本次模拟实时生成；LLM/认知层与规则引擎职责
分离；改变一个条件后，差异能沿事件和状态更新追溯。

## 启动

环境要求：Python 3.11+、`uv`、Node.js 22+。

```bash
make demo-stack
```

打开 <http://localhost:3000>，点击首页“进入五分钟演示”。若只需检查生成数据：

```bash
uv run insidegov demo --seed 42 --fiscal-multiplier 0.5
```

该演示默认使用确定性认知层，断网可运行，不需要 API Key，也不消耗模型 Token。

## 六步讲解

1. **公开事实与模型假设**：指出70亿元投资、财政收入等公开来源，同时标明25%可动用
   财力和基金拆分是校准/模型假设。
2. **企业表达与政府澄清**：展示企业第一轮表达、政府问题、披露项和信念更新；企业真实
   门槛仍是私有信息。
3. **政府内部会商**：招商局提出现金18.47亿元，财政局将现金压到9.54亿元并限制本级
   股权，市领导在硬约束内重组工具。
4. **条件合同与联合基金**：本级财政股权16.48亿元，三个独立资金池核准53.52亿元，
   合计70亿元；每笔款项有资金来源、季度和触发条件。
5. **跨期规则结算**：查看承诺状态、支付额、财政扣减、信用和项目进度；模型不能直接
   修改这些状态。
6. **共同随机数反事实**：两个世界共享Q3状态和随机数，只在Q4将合肥可用财力乘以0.5；
   下钻延期事件，解释Q16供应商、就业和信用差异。

## 报告中心

点击“实验结果”可从策略/消融均值下钻到单个 seed，查看世界归档、失败和降级原因，
并导出 JSON。报告中心优先读取本地 `.insidegov/reports`，没有本地矩阵时使用仓库随包
发布的 P1 报告。

## 发布前验收

```bash
make verify
```

人工浏览器验收：

- 首页能看到“五分钟典型博弈回放”和“实验结果”；
- 点击演示后出现六个步骤，并显示本次生成的两个不同 world ID；
- 内部会商显示提案、财政上限、最终方案和四个行动回合；
- 合同页显示三个基金资金池和八项承诺；
- 反事实页显示共同祖先Q3、Q4干预及Q16差异；
- 报告中心可选 seed、查看失败案例并下载 JSON；
- 浏览器控制台无错误，API Key 缺失不会阻断确定性演示。

## 演示边界

案例是“机制校准与可审计演示”，不是对历史交易主体和效果的一一复刻。反事实差异是
当前规则与参数下的模拟结果，不是现实政策效果估计。来源、假设与敏感性详见
[2020合肥—蔚来参数卡](cases/HEFEI_NIO_2020.md)。
